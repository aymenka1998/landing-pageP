# صفحة الساعة الذكية برو

صفحة متجر عربية باتجاه RTL، مبنية بـ Next.js. تستقبل الطلب عبر واتساب، ويمكنها اختياريًا تسجيل الطلبات في Google Sheets.

## قبل الإطلاق

راجع هذه البيانات في `src/config/product.json` قبل نشر الموقع:

- تأكد من رقم واتساب، السعر، العملة، الصور، المدن ومعلومات المنتج.
- حدّث البريد الإلكتروني في حقلي `email` و`footer.email` إذا كان لديك بريد دعم. اتركهما فارغين لإخفاء البريد من تذييل الصفحة.
- راجع ادعاءات المنتج والضمان والإرجاع والتقييمات، وتأكد أنها تطابق ما تقدمه فعليًا.
- إذا أردت حفظ الطلبات في Google Sheets، جهّز Web App من `google-apps-script.js`؛ وإلا فلا تحتاج أي متغيرات بيئة للإطلاق.

## معاينة محلية على Windows

1. ثبّت Node.js LTS.
2. افتح PowerShell في مجلد المشروع وشغّل `npm ci`.
3. شغّل `npm run dev` ثم افتح `http://localhost:3000`.

## النشر على الإنترنت عبر GitHub وVercel

1. افتح المشروع في GitHub Desktop، ثم اختر **Publish repository**. اجعل المستودع **Private** إذا كنت لا تريد نشر ملفات المصدر للعامة.
2. افتح Vercel وسجّل الدخول باستخدام GitHub، ثم اختر **Add New → Project** واستورد مستودع الصفحة.
3. اترك إعداد Framework على **Next.js** وإعدادات البناء الافتراضية. لا يحتاج المشروع إلى ملف إعداد خاص بـ Vercel.
4. إذا أعددت Google Sheets، أضف `GOOGLE_SHEET_WEBHOOK` في إعدادات المشروع على Vercel، واختر بيئات Production وPreview حسب حاجتك. لا تضف بادئة `NEXT_PUBLIC_` لهذا الرابط.
5. اضغط **Deploy**. سيمنحك Vercel عنوانًا عامًا للموقع؛ ويمكن ربط نطاقك من إعدادات المشروع لاحقًا.
6. بعد نجاح النشر، جرّب إرسال طلب تجريبي وتأكد من انتقالك إلى واتساب، ومن وصول الصف إلى Google Sheets إذا أعددته.

بعد ربط المستودع، كل تحديث ترفعه إلى GitHub يبدأ عملية نشر جديدة تلقائيًا. لوحة التحكم التي تأتي مع هذا المنتج مخصصة للتشغيل على جهازك عبر الشبكة المحلية؛ لا ترفع خادمها المحلي إلى Vercel.

## متغيرات البيئة

| المتغير | مطلوب؟ | الاستخدام |
| --- | --- | --- |
| `GOOGLE_SHEET_WEBHOOK` | لا | رابط Google Apps Script Web App لتسجيل الطلبات في جدول البيانات. اتركه غير مضبوط إذا لم تستخدم Sheets. |

لا ترفع `.env.local` إلى GitHub. الملف مستثنى في `.gitignore`. إعداد Vercel للمتغيرات متاح من **Project Settings → Environment Variables**؛ أعد النشر بعد إضافة متغير جديد.

## تعديل المنتج

- النصوص والأسعار والمدن والأسئلة والصور المعرّفة: `src/config/product.json`.
- ملفات الصور: `public/images`.
- تخطيط الصفحة وأقسامها: `src/components`.
- بيانات الطلبات إلى Google Sheets: `google-apps-script.js`.

## أوامر المشروع

- `npm ci` تثبيت الاعتمادات من ملف القفل.
- `npm run dev` تشغيل المعاينة المحلية.
- `npm run build` إنشاء نسخة الإنتاج والتحقق من جاهزيتها للبناء.
- `npm start` تشغيل نسخة الإنتاج بعد نجاح البناء.
